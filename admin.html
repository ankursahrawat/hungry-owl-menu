📲 Telegram Order Delivery

Set these as environment variables in your Vercel project (Settings → Environment Variables), then redeploy: TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID. They're never sent to this page or stored in the database — only your server sees them, which is why there's no field to type them here.

To get these: message @BotFather on Telegram to create a bot and get its token, then message @userinfobot (or add the bot to a group) to get the chat ID.

🔑 Change Staff PIN

Set the ADMIN_PIN environment variable in Vercel to change the PIN, then redeploy. It's kept out of the page source this way.

Drag the ⠿ handle to reorder categories, or reorder items inside a category. Changes save automatically and appear for customers within about 15 seconds.
