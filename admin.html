💬 WhatsApp Order Delivery

Orders are sent directly to your WhatsApp via the Meta Cloud API. Set these in Vercel (Settings → Environment Variables), then redeploy:

  • WHATSAPP_TOKEN — permanent access token from Meta Business Suite
  • WHATSAPP_PHONE_ID — Phone Number ID from your Meta WhatsApp dashboard
  • WHATSAPP_TO — your shop WhatsApp number with country code, no + (e.g. 919308006900)

If WhatsApp API isn't configured, customers are redirected to open WhatsApp directly with the order pre-filled.

🔑 Change Staff PIN

Set the ADMIN_PIN environment variable in Vercel to change the PIN, then redeploy. It's kept out of the page source this way.

Drag the ⠿ handle to reorder categories, or reorder items inside a category. Changes save automatically and appear for customers within about 15 seconds.
