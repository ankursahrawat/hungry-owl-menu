📲 Telegram Order Delivery

Customers tap "Send Order" and it's delivered straight to your Telegram automatically. To set this up: message @BotFather on Telegram, create a bot, and paste its token below. Then message @userinfobot (or add your bot to a group) to get your Chat ID.

⚠️ This page has no private server, so this token is stored in shared, publicly-readable data and visible to anyone who inspects the page. Create a dedicated bot just for this menu — never reuse a token from a bot used elsewhere. Worst case someone abuses it to spam messages to this one chat; it can't access anything beyond that.

If you'd rather not expose a token at all, leave this blank — "Send Order" will instead let customers share the order image straight from their phone's share sheet (Telegram, WhatsApp, etc.), or download it if that's unavailable.
